# 植物性状提取工具 使用教程

导入你的CSV定义性状 → 粘贴植物描述 → AI自动提取 → 检查确认 → 导出Excel。

---

## 快速开始（3步）

### 第1步：导入CSV，定义有哪些性状
点击顶部「📥 导入CSV」，选择你的CSV文件。

- CSV第一行是性状名称（如 `taxon, leaf_shape, leaf_color`）
- 第一列建议是物种名（列名写 `taxon`）
- 只有表头也行，数据行可选

### 第2步：粘贴植物描述，AI提取
1. 把植物形态描述粘贴到左边文本框（或用URL抓取）
2. 点击「🤖 AI提取性状」
3. 等几秒，右边字段就自动填好了

### 第3步：检查并保存
1. 看看右边提取的值对不对，不对可以手动改
2. 点击「✅ 添加到记录列表」保存这条
3. 全部提取完后，点击「📊 导出Excel」下载

---

## 常用功能

### 🔧 字段配置（让AI提取更准）
点击「⚙️ 字段配置」，每个性状可以填：

| 填什么 | 作用 | 例子 |
|--------|------|------|
| 提取说明 | 告诉AI这个字段要什么 | "叶片形状，注意是单叶不是复叶" |
| 标准词 | 设几个标准答案，AI自动归类 | "卵形,披针形,圆形" |

设了标准词后，AI提取完会弹出映射表让你检查：
- 原始描述 → AI归类为 → 你可以下拉修改
- 确认后缓存，下次遇到同样描述直接用
- 可以选「忽略此值」丢弃识别错误的内容

也可以直接导入配置CSV批量填写，格式：
```csv
field,desc,standard_examples
leaf_shape,叶片形状,卵形,披针形,圆形
leaf_color,叶片颜色,绿色,黄绿色,灰绿色
```

### 📐 尺寸字段自动展开
如果CSV里性状名是 `leaf_size_length` 这种，会自动变成5个值：
- 最小、最大（典型范围）
- 极端最小、极端最大（括号里的极值）
- 平均（自动算，不用填）

导出时只出平均值一列。

### 🖱️ 划词手动填入
AI没提取到的，可以手动补：
1. 在左边文本框选中一段文字
2. 点击右边对应性状的名称
3. 选中的文字就填进去了

### 🔍 查看来源高亮
提取完后，点击右边性状名称（没选中文本时），左边原文会高亮这个值的出处，方便核对。

### 📁 批量处理多个物种
1. 每个物种存一个TXT文件（文件名用物种名）
2. 点击「📁 批量导入TXT」，全选所有文件
3. 左边出现队列，自动加载第一个
4. 提取完点「添加到记录列表」，自动跳下一个
5. 随时点队列里的物种名切换查看

### 🔗 映射管理
点击「🔗 映射管理」，可以查看和修改之前确认过的所有归类：
- 按字段筛选、关键词搜索
- 修改归类、标记忽略、删除单条
- 导入/导出映射表

修改后下次提取生效，已保存的记录不变。

---

## 导出
点击「📊 导出Excel」，所有保存的记录导出为CSV，Excel可直接打开。
- 空的性状不导出
- 尺寸字段只导出平均值

---

## 常见问题

**Q：AI提取不准？**
A：在字段配置里写更详细的「提取说明」，并设置标准词让AI归类。

**Q：点性状名称变成填入而不是高亮？**
A：说明你之前在文本框选过文字。点一下页面空白处清空选区，再点性状名称就是高亮了。

**Q：如何初始化？**
A：顶部有重置按钮，别人打开后自己配API和导入CSV。

**Q：API怎么填？**
A：点「🔑 API设置」，填你的API密钥和模型名，地址默认火山引擎Ark。

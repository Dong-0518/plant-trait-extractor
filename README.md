# 植物性状提取工具

基于AI的植物形态学性状批量提取工具，结合rwcvp获取全球物种名录，支持在线从中国植物志(FOC)和北美植物志(FNA)抓取描述文本。

### 环境要求

- Python 3.9+
- R 4.0+
- Edge浏览器

### 安装步骤

1. **克隆或下载本仓库**

2. **安装Python依赖**
```bash
pip install flask flask-cors requests beautifulsoup4 playwright
```

3. **安装R包**
```r
install.packages("remotes")
remotes::install_github("matildabrown/rWCVP")
install.packages(c("jsonlite", "dplyr"))
```

4. **启动后端服务**
   - Windows: 双击 `start.bat`
   - 手动: `python server.py`

5. **打开前端**
   - 双击 `index.html` 在浏览器中打开

## 使用流程

1. 点击「⚙️ 设置」配置你的API Key（OpenAI兼容格式）
2. 点击「字段配置」导入性状字段CSV（第一列是taxon物种名，后续列是性状字段）
3. 开始提取：
   - **手动模式**：直接粘贴植物描述文本，点击AI提取
   - **批量模式**：批量导入TXT文件，逐个处理
   - **在线抓取**：输入科名/属名，自动获取物种名录并抓取FOC/FNA描述
4. 审核AI提取结果，修改错误映射
5. 导出Excel

### 🔧 字段配置

点击「⚙️ 字段配置」，每个性状可以填：

| 填什么   | 作用                       | 例子                           |
| -------- | -------------------------- | ------------------------------ |
| 提取说明 | 告诉AI这个字段要什么       | "叶片形状，注意是单叶不是复叶" |
| 标准词   | 设几个标准答案，AI自动归类 | "卵形,披针形,圆形"             |

设了标准词后，AI提取完会弹出映射表让你检查：

- 原始描述 → AI归类为 → 你可以下拉修改
- 确认后缓存，下次遇到同样描述直接用
- 可以选「忽略此值」丢弃识别错误的内容

也可以直接导入配置CSV批量填写，格式：

```csv
field,desc,standard_examples
leaf_shape,叶片形状,卵形,披针形,圆形
leaf_color,叶片颜色,绿色,黄绿色,灰绿色
```

### 📐 尺寸字段自动展开

如果CSV里性状名是 `leaf_size_length` 这种，会自动变成5个值：

- 最小、最大（典型范围）
- 极端最小、极端最大（括号里的极值）
- 平均（自动算，不用填）

导出时只出平均值一列。

### 🖱️ 划词手动填入

AI没提取到的，可以手动补：

1. 在左边文本框选中一段文字
2. 点击右边对应性状的名称
3. 选中的文字就填进去了

### 🔍 查看来源高亮

提取完后，点击右边性状名称（没选中文本时），左边原文会高亮这个值的出处，方便核对。

### 📁 批量处理多个物种

1. 每个物种存一个TXT文件（文件名用物种名）
2. 点击「📁 批量导入TXT」，全选所有文件
3. 左边出现队列，自动加载第一个
4. 提取完点「添加到记录列表」，自动跳下一个
5. 随时点队列里的物种名切换查看

### 🔗 映射管理

点击「🔗 映射管理」，可以查看和修改之前确认过的所有归类：

- 按字段筛选、关键词搜索
- 修改归类、标记忽略、删除单条
- 导入/导出映射表

修改后下次提取生效，已保存的记录不变。

## 配置说明

所有路径都在「🌐 在线抓取」界面里配置，不用手动改文件。

### Rscript路径（物种名录用）

后端启动时会自动查找R安装路径。如果自动查找失败：
1. 打开「🌐 在线抓取」界面
2. 找到「Rscript路径」输入框
3. 点「自动查找」，或者手动输入Rscript.exe的完整路径
4. 路径自动保存，下次启动不用再配

### Edge路径

FNA有Cloudflare防护，需要配合Edge浏览器调试模式：
1. 打开「🌐 在线抓取」界面
2. 找到「Edge路径」输入框
3. 点「自动查找」，或者手动输入msedge.exe的完整路径
4. 点「启动调试模式」按钮，自动打开Edge调试窗口
5. 保持那个Edge窗口开着，然后点「抓取FNA描述」

如果遇到Cloudflare验证，在那个Edge窗口里手动点一下就行。

### API配置

支持所有OpenAI兼容格式的API：
- 火山引擎豆包
- OpenAI
- 其他兼容服务

## 数据说明

- 所有数据保存在浏览器localStorage中，不上传任何服务器
- 支持导出备份JSON文件，换电脑时可恢复
- 不同版本的存储键名不同，互不干扰

## 注意事项

- 后端服务必须保持运行，关闭后在线抓取功能不可用
- FNA有Cloudflare防护，抓取时需要保持Edge调试窗口开着
- rwcvp需要联网下载WCVP数据库
